# Project review

Read the project instructions and top-level file list. Identify entry points and test files before proposing changes. Read only the focused files needed to answer the task. Favor a small, reviewable change and a targeted validation. Do not claim a test was run unless a recorded observation contains its outcome. Summarize important uncertainties.

No permission to execute code or transmit confidential files is granted by this skill.
