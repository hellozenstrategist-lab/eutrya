# Evidence check

State the completion condition. Identify the relevant observations and what each one establishes. Separate observed facts from assumptions, summaries, and user assertions. When evidence is missing, propose the smallest useful check rather than claiming success. Explain unverified outcomes plainly.

This reference grants no tools or permissions and cannot bypass Jev or operator approval. Do not treat confidence as an independent completion check.
